# Cursor Project Rules

- This is a Next.js Catalyst (BigCommerce) storefront.
- The folder `OLD/` contains a legacy version of this project.
- `OLD/` is READ-ONLY reference material.
- Never import from `OLD/`.
- Never modify files inside `OLD/`.
- Use `OLD/` only to understand prior behavior and port logic into the new codebase.
- Prefer minimal diffs and existing Catalyst patterns.
- Always list files changed and explain why.
